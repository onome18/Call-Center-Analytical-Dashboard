# Call-Center-Analytical-Dashboard
This project presents a Call Centre Analytical Dashboard designed to provide a comprehensive view of operational metrics and customer service performance. It highlights key KPIs, call trends, agent performance, and customer demographics to support data-driven decision-making.


# ☎️ Call Centre Analytical Dashboard

## 📈 Dashboard Highlights

### 🔹 Key Performance Indicators (KPIs)
- **Total Calls:** 1,000  
- **Total Revenue (Amount):** $96.62K  
- **Average Call Duration:** 89.85 seconds  
- **Customer Rating:** 4.00 / 5.00  

### 🔄 Call Trend Over Time
- Monthly breakdown from January to December
- Highest call volume recorded in **April (155 calls)**

### 👨‍💼 Calls & Revenue by Representatives
- Tracks both **total call volume** and **total amount generated**
- Top performers:
  - **R03:** $21K from 207 calls  
  - **R02:** $21K from 218 calls  
  - Others (R01, R04, R05) show consistent contributions

### 🗓️ Calls by Day of the Week
- Peak call days: **Saturday & Wednesday** with $16K each
- Lower call volumes on Thursdays and early weekdays

### 🧍 Gender Distribution
- **59.9% Male**  
- **40.1% Female**  

### 🌍 Geographic Distribution
- Most calls originate from cities like:
  - **Cleveland**
  - **Cincinnati**
  - **Columbus**
